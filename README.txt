FiribStop UZ — Offline Shield 2.5.1 · Signature UI

Обновление интерфейса 2.5.0:
- Переработана визуальная система: больше воздуха, выразительная типографика, аккуратная сетка и единый стиль карточек, кнопок, полей и навигации.
- Светлая тема использует белые поверхности и тёмный текст; тёмная тема имеет отдельную палитру с хорошим контрастом.
- Адаптивная боковая навигация и карточки настроены под desktop и мобильные экраны.
- Карта получила оформление, сочетающее чистую светлую подложку с фирменными акцентами UZ:Cyberpunk; тёмная тема использует отдельное оформление.
- Service Worker обновлён до v22, чтобы браузер загрузил новую оболочку приложения.

Карта показывает административные границы и текстовые упоминания в публикациях. Она не является подтверждённой статистикой атак в реальном времени. Число публикаций не равно числу инцидентов. Картографические тайлы и свежая лента новостей требуют интернета.

Запуск:
1. Требуется Node.js 18 или новее.
2. Выполните npm install (для базового сервера дополнительных пакетов не нужно).
3. Выполните npm start.
4. Откройте http://localhost:3000.

Развёртывание на Render: используйте настройки из render.yaml. После публикации очистите кеш браузера или выполните Ctrl+Shift+R.

Проверки: npm test.

Версия 2.5.0 — профессиональная доработка:
- Заголовки безопасности (CSP, X-Frame-Options, Permissions-Policy, HSTS), CSP пока содержит 'unsafe-inline' из-за встроенных обработчиков в index.html.
- Лимит запросов к /api (RATE_LIMIT, по умолчанию 120 в минуту на IP; за прокси включите TRUST_PROXY=1, это уже сделано в render.yaml). Принудительное обновление новостей не чаще раза в минуту.
- Dockerfile (непривилегированный пользователь, healthcheck), корректное завершение по SIGTERM.
- CI на GitHub Actions (Node 18/20/22) запускает npm test.
- «Приватный режим» в разделе «История»: текст проверок не сохраняется в браузере.
- Тесты: npm test (анализатор, сервер, заголовки, лимиты).

2.5.1: исправлена подложка карты. Service Worker больше не перехватывает сторонние запросы (плитки карты, CDN): после добавления CSP в 2.5.0 такие запросы блокировались. Подложка теперь пробует по очереди OpenStreetMap, CARTO, OpenStreetMap DE и Esri; если сеть блокирует все, границы областей и новости работают без неё.
